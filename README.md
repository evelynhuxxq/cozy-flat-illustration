# cozy-flat-illustration

An image-generation skill for turning photos into comforting, graphic, hand-painted travel and storybook scenes. It keeps the main story of the photo, gives visible people complete kind faces, and adds small details that fit the setting.

## Structure

```
SKILL.md                 # the complete skill
tools/stamp-frame.html   # optional, repeatable postage-stamp border maker
```

The repository root is the skill package—there is no nested copy to install.

## Use

Add this repository folder to your skills directory, then attach a photo and ask for a cozy flat illustration. The skill generates the finished illustration directly and can add a stamp edge when requested.

## Optional stamp border

Open `tools/stamp-frame.html` in a browser, choose a finished illustration, select any border color, and download the framed PNG. Leave the caption fields blank for a clean border-only stamp.
